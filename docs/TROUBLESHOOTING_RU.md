# Если что-то сломалось (коротко)

**Агент молчит.** Actions → agent-cycle: есть ли запуск с «In progress»? Нет — нажми Run workflow. Запуски идут цепочкой: цикл сам ставит следующий (если не выключен `/autorun off` и нет файла STOP).

**Сообщение «Сторож: файл … не загрузился».** Агент работает без этого файла. Открой Actions → check-parts или шаг Pre-flight, найди строку PART_GUARD, пришли её Claude или удали/откати файл.

**«Сторож: модели не отвечают N раз подряд».** Обычно кончились бесплатные лимиты. Проверь `/limits`. Лимиты обнуляются в 03:00 по Москве (Groq) и около 11:00 (Gemini). Само пройдёт.

**Шаг Pre-flight красный.** Файл в `parts/` или `scripts/` сломан. В логе шага: COMPILE (синтаксис), PART_GUARD (файл упал или затёр функцию), SELFTEST FAILED (нарушено обещание агента). Откати последний загруженный файл (History файла → Revert).

**Цикл упал сразу.** Если сломан основной файл (`part_01`, `part_05`, `part_06_owner_chat`), в логе будет «differs from the pinned hash»: файл и хеш в `agent.py` надо менять вместе.

**Нужно остановить совсем.** Создай пустой файл `STOP` в корне репозитория (агент остановится за несколько минут и цепочка не продолжится). Полностью: Actions → agent-cycle → ⋯ → Disable workflow. Включить обратно: удали STOP и Enable workflow.

**Новая ветка вместо main.** При загрузке выбирай Commit directly to the main branch. Лишнюю ветку удали в Branches.

**Откат модуля `own/`.** `/own off имя.py` (выключить) или `/own del имя.py` (удалить).
