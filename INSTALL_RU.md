# Стабилизация 2026-11-20 — как загрузить (один раз, одним архивом)

Распакуй архив. Внутри папки повторяют структуру репозитория agent.

1. Репозиторий codexofweights_agent → Add file → Upload files. Перетащи ВСЁ содержимое распакованной папки (agent.py, папки parts, scripts, .github). Если телефон не даёт перетащить папки — загрузи по частям: agent.py в корень; parts/part_06zzy_watchdog.py в parts; scripts/preflight.py в scripts; два файла .yml в .github/workflows.
2. Commit changes.
3. Actions → agent-cycle → Cancel workflow (текущий запуск) → Run workflow. (agent.py подхватится только с нового запуска.)
4. Через минуту во вкладке Actions должен появиться зелёный запуск check-parts (проверка файлов). Красный = в загруженном есть ошибка.

Что это даёт:
- agent.py: сломанный необязательный файл больше не валит агента. Он пропускается, а то, что он затёр (как http), возвращается на место.
- part_06zzy_watchdog.py: сторож пишет в Telegram, если файл пропущен, и если модели не отвечают 8 раз подряд.
- check-parts.yml: при каждой загрузке файлов проверяет, что всё загружается.
- agent.yml: проверка перед каждым циклом + сообщение в Telegram, если она красная. Заодно вернул LINKUP_API_KEY и `own` в git add.
