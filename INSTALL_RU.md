## Что нового

- `/make описание` — агент сам делает модуль для себя (дизайн, тесты, код, рецензия другой моделью), ты решаешь `/own ok ID` или `/own no ID`.
- `/scout нужда` — ищет идею на GitHub (только открытые лицензии, читает только README, ничего не скачивает и не запускает); `/scout make ID N` отдаёт идею в `/make`.
- `/tip` — подсказки себе ниже Кодекса, предлагает сам раз в неделю, решаешь ты.
- `/note` — блокнот по коду и приёмам.
- `/model` — новые бесплатные модели: раз в неделю агент находит новые, тестирует нашими замерами и предлагает хорошие.
- `/own` — список собственных модулей, `off|on|del имя.py`.
